===================================================================
   AtomicDB Portable — Ready-to-Run USB Folder
===================================================================

This folder is completely self-contained and ready to copy to a USB drive.

HOW TO USE:
1. Double-click "AtomicDB.exe" or "START_HERE.bat".
2. The application will start immediately.
3. Select your CPU mode or thread count and click "Start Contributing".

NOTES:
- Zero installation or administrator privileges required.
- Everything runs portably from this USB folder (zero host C: trace).
- Real-time CPU and RAM telemetry refreshes every 0.8 seconds.
- Adaptive Mode automatically leaves 50% of the host machine's cores off (evaluated every 20s) for responsive multitasking.
- Diagnostic Dashboard with Session & Lifetime Statistics:
  * Session Statistics: Tasks, Nodes, Current NPS, Avg NPS, Session Uptime.
  * Current Task: Task ID, Nodes, Calculating Line, and ETA based on average NPS of last 3 tasks.
  * Lifetime Statistics: Preserved permanently in logs/lifetime_statistics.txt (never cleared).
  * Real-time Graphs: CPU usage over time, RAM usage over time, NPS per task.
- History, metrics, crashes, and tablebases are all stored directly in logs/ and syzygy-345/ on this drive.
