===================================================================
   Background Processing Utility — Ready-to-Run USB Notes
===================================================================

HOW TO USE:
1. Double-click "Background Processing Utility.exe" (or "RUN_ATOMICDB.bat") in the main folder.
2. Adjust settings in the "API Parameters" tab if needed and click "Start".
3. Optional account attribution: edit "account.txt" and set USERNAME=... and PASSWORD=...
   (leave blank to use the built-in default account).

NOTES:
- Zero installation or administrator privileges required.
- Everything runs portably from this USB folder (zero host C: trace).
- Real-time CPU, RAM, and ETA telemetry refreshes every 1 second.
- Adaptive Mode automatically leaves 50% of the host machine's cores off (evaluated every 20s).
- Full-screen tabs: API Parameters, Live Analysis Console, Graph and Analytics.
- Logs & lifetime metrics are stored directly in logs/ on this drive and never cleared.
